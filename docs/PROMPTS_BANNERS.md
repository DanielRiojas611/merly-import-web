# Banners De Merly Import

Prompts de referencia para generar banners del catalogo mayorista de Merly Import.

## Marcas Y Catalogo

`Crea un banner horizontal 1600x600 para una importadora mayorista peruana llamada Merly Import. Usa productos de higiene, limpieza y hogar agrupados a la derecha con iluminacion de estudio y sombras naturales. Deja el 55 % izquierdo limpio para texto web. Paleta rojo y azul inspirada en el logo real de Merly Import. Sin texto ni logo incrustado.`

## Preventa

`Crea un banner horizontal 1600x600 sobre preventa mayorista y abastecimiento planificado. Muestra cajas y productos listos para despacho, con sensacion de orden, volumen y confianza comercial. Paleta rojo, azul y blanco. Sin texto ni logo incrustado.`

## Entregas

`Crea un banner horizontal 1600x600 sobre entrega coordinada para Lima y provincias. Muestra cajas de productos listas para despacho y una referencia visual sutil a envios nacionales. Deja el 55 % izquierdo limpio. Paleta azul con acentos rojos. Sin texto ni logo incrustado.`
